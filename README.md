# 👾 Pokémon Explorer (pokemon_game)

A cross-platform React Native application for exploring Pokémon cards, built with Expo and Redux.

## 🚀 Features
- **Dynamic Pokémon List:** Explore a variety of Pokémon cards with detailed stats.
- **State Management:** Powered by **Redux Toolkit** for consistent data flow across the app.
- **Haptic Feedback:** Professional feel using `expo-haptics` for tactile interactions.
- **Navigation:** Seamless screen transitions using **React Navigation**.
- **Responsive Design:** Optimized for both iOS and Android devices.

## 🛠️ Tech Stack
- **Framework:** [React Native](https://reactnative.dev/) (Expo)
- **State Management:** [Redux Toolkit](https://redux-toolkit.js.org/)
- **Navigation:** [React Navigation](https://reactnavigation.org/)
- **Haptics:** [Expo Haptics](https://docs.expo.dev/versions/latest/sdk/haptics/)

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd ExerciseOne
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npx expo start
   ```

4. **Run on your device:**
   - Scan the QR code with the **Expo Go** app (Android) or **Camera** app (iOS).
   - Press `i` for iOS Simulator or `a` for Android Emulator.
